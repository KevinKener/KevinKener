## 🚀 Proyectos

### 🍔 Black & White — PWA de Fidelización *(freelance · en desarrollo)*

> Sistema de puntos para una cadena de dos locales de hamburguesas. PWA sin necesidad de descarga, integrada con WhatsApp para el flujo de pedidos. **Primer proyecto profesional pago.**

**Stack:** `React + Vite` · `Node.js + Express + TypeScript` · `PostgreSQL` · `Supabase` · `Vercel`

**Herramientas:** `Claude Code` · `Gemini Stack (gstack)`

- Panel admin por local: gestión de pedidos, clientes y canjes
- Sistema de puntos automático al confirmar cada pedido
- El cliente recibe su saldo por WhatsApp — sin app store, funciona en cualquier celular
- Deploy en la nube con Vercel + Supabase como backend

[![Repo](https://img.shields.io/badge/GitHub-blackandwhite-181717?style=flat-square&logo=github)](https://github.com/KevinKener/blackandwhite)
